Thanujana D.O

ID: IT22148704 • SLIIT Computing
Connectivity, Mesh Intelligence & Compass

Engineered TrailLink’s foundational connectivity and mesh layer, providing autonomous backend reachability detection, situational peer link intelligence, on-device spatial signal guidance, and bounded packet forwarding across nearby phone links without cellular infrastructure or external hardware.

⚡ Key Contributions & Algorithmic Innovations
  • Active HTTP Reachability Probe: 4-state hysteresis state machine (Online, Offline, Reconnecting, Unstable) eliminating false OS-level Wi-Fi connection assumptions.
  • Composite Link Quality Estimation (LQE): Deterministic pipeline scoring peer health (0–100) across five labelled tiers with split-half trend analysis (±10 delta threshold).
  • On-Device Network Compass: Privacy-preserving sensor fusion coupling local GPS with 262 KB HTTP throughput probing for geodesic directional guidance (±1° bearing accuracy).
  • Controlled Mesh Relay Engine: Application-layer relay enforcing allow-lists, channel scoping, origin exclusion, and TTL/hop-count budgets (max 5 hops) to prevent broadcast storms.
◆ ±10 LQE Delta ◆ ±1° Bearing Guidance ◆ 4-State Hysteresis ◆ Max 5-Hop Budget ◆ 262 KB Probe Engine
✉

Dulsara H G N

ID: IT22544490 • SLIIT Computing
Geospatial Mapping & SOS

Spearheaded TrailLink’s local-first spatial awareness, vector/raster topographic mapping, priority distress dissemination protocol, and transactional dual-state cloud database synchronization for infrastructure-less expeditions and search-and-rescue operations.

⚡ Key Contributions & Algorithmic Innovations
  • Unprivileged GNSS Ingestion: Continuous coordinate telemetry sampling serialized into compact 512-byte MTU JSON framing operating without Android root permissions.
  • Offline MBTiles Vector Rendering: Local vector/raster map rendering across 25 km² wilderness zones coupled with mathematical 3-tier temporal decay ƒfreshness(Δt) (Fresh ≤5m, Old 5–15m, Stale >15m).
  • Priority Emergency SOS Preemption: Out-of-order queue preempting media traffic, bounded by strict Time-To-Live (TTL=8, ≤ 5 hops), split-horizon loop suppression, and duplicate ledger (processed_offline_packets).
  • Transactional BridgeEngine Reconciliation: Synchronous relational WAL SQLite persistence with automated batched cloud reconciliation to MongoDB, guaranteeing zero data loss across 750 empirical trials (sub-850ms multi-wall latency).
◆ 99.5% PDR @ 20m ◆ < 850 ms SOS Latency ◆ 3-Tier Freshness Decay ◆ 0% Data Loss Cloud Sync ◆ 750 Physical Trials
✉

Pabodhana D M D I

ID: IT22168290 • SLIIT Computing
Communication Core

Engineered TrailLink's central transport backbone, providing seamless switching between online cloud APIs and offline P2P mesh messaging with guaranteed local data persistence and delivery reliability.

⚡ Key Contributions & Algorithmic Innovations
  • Transactional Store-and-Forward Engine: SQLite-backed resilient outbox manager guaranteeing zero message loss across unexpected process terminations and transport transitions.
  • Loop-Free Multi-Hop TTL Relaying: Decentralized hop forwarding protocol with idempotent sequence filtering achieving 0.00% duplicate loop rate across mesh nodes.
  • SOS Priority Preemption: Dynamic queue scheduling intercepting routine conversational buffers for sub-second emergency packet propagation.
  • Empirical Mesh Latency Benchmark: Validated multi-hop delivery with a sub-390ms 4-hop propagation latency benchmark across physical handset clusters.
◆ Sub-390ms 4-Hop ◆ 0.00% Loop Rate ◆ Store-and-Forward ◆ Zero-Loss Outbox
✉

Vitharana G.G

ID: IT22894038 • SLIIT Computing
Voice and Push-to-Talk (PTT) Communication

Engineered TrailLink’s voice layer, giving groups validated, replayable voice notes and floor-controlled Live Radio that work online through the cloud and offline over nearby phone links, with cleanup that never drops the group connection.

⚡ Key Contributions & Algorithmic Innovations
  • Validated Voice-Note Pipeline: Filters corrupted clips under 650 ms or 128 bytes, prevents duplicate releases, and marks delivered status strictly upon peer acknowledgment.
  • Serverless PTT Floor Control: Decentralized token arbitration rule with deterministic tie-breaking and automatic voice stream muting upon incoming SOS alerts.
  • 7-State Live Radio Engine: Real-time audio streaming pipeline pushing 200 ms PCM chunks with idempotent session cleanup isolated from the Nearby connection.
  • Payload Budget & Codec Optimization: Strict 32 KB Nearby packet ceiling analysis capping single-packet clips at ~24 KB raw audio to prevent fragmentation.
◆ 200ms PCM Streams ◆ 24 KB Audio Cap ◆ Deterministic PTT Tie-Break ◆ 7-State Radio FSM ◆ Auto SOS Voice Muting
